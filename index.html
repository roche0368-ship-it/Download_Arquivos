Como funciona

Esta é uma aplicação HTML independente. Os registros ficam salvos no armazenamento local do navegador utilizado.

Atenção: os dados não são enviados para a internet nem compartilhados automaticamente com outros técnicos. Se limpar os dados do navegador ou trocar de computador, poderá perder os registros. Faça backups regularmente.

Backup e restauração

Use Exportar backup para baixar um arquivo JSON com seus registros. Para restaurar, selecione um backup exportado anteriormente.

Limitações desta versão

• Não possui login nem controle de permissões.
• Não sincroniza entre computadores ou técnicos.
• Não armazena anexos; registra apenas referências.
• Para uso compartilhado pela equipe, será necessário hospedar a aplicação com backend e banco de dados.

Excluir registro?

Essa ação não poderá ser desfeita. Recomendamos exportar um backup antes.
